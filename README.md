# Orca_Anycubic_Kobra_3_MAX
This allows control of an Anycubic Kobra 3 MAX Printer through OrcaSlicer while the printer is on LAN mode

This is a very simple plugin with a decent graphical interface allowing for basic control as a printer agent inside Orca Slicer 2.5 and above.

This was primarily created with the help of ChatGPT, but I am a data analyst with some Python programming experience, and I have looked the code over. I can't say I completely understand how the system decoded the protocol to the printer, but it seems to work ok.

Please note that this is a use at your own risk sort of deal. I make no promises of its suitability or safety, just that I didn't prompt the system to generate any kind of malicious code. Feel free to ask for fixes or you can contribute if you'd like.
